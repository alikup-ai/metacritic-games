# Исследование: per-platform Metascore и Userscore на Metacritic

**Дата:** 2026-09-07
**Статус:** завершено, OQ-18 закрыт
**Метод:** живые HTTP-запросы (обычный User-Agent, без headless-браузера)

---

## 1. Цель

Согласно решению Product/Tech Lead по OQ-18, до реализации ingestion требовалось:

- достоверно определить, можно ли связать Metascore и Userscore с конкретной платформой;
- проверить минимум несколько игр с несколькими платформами;
- **не делать предположений на основании HTML/CSS, если связь не доказуема.**

---

## 2. Итоговый вывод

**Связь Metascore → платформа доказана.** Оценки различаются между платформами и надёжно
привязаны к ним в разметке.

**Связь Userscore → платформа доказана частично:** агрегированный Userscore на платформу
напрямую не публикуется, но каждый пользовательский отзыв содержит поле `platform`.

Итог по политике `score_scope`:

| Метрика | Связь с платформой | `score_scope` |
|---|---|---|
| Metascore | Доказана | `platform` |
| Userscore (общий) | Не публикуется по платформам | `overall` |
| Userscore (вычисленный) | Возможен из отзывов | **не используется на MVP** (см. §6) |

---

## 3. Доказательство: Metascore по платформам

### Разметка

Каждая платформа представлена карточкой `product-score-card`. Название платформы — в
атрибуте `title` иконки внутри `game-platform-logo`:

```html
<div class="game-platform-logo">
  <span class="iconify i-mc-platform:ps5logo ... " title="PlayStation 5"></span>
</div>
```

В той же карточке — количество рецензий и балл.

### Игра 1 — `elden-ring`

| Платформа | Metascore | Критиков |
|---|---|---|
| PC | **94** | 63 |
| Xbox Series X | **96** | 19 |
| PlayStation 5 | **96** | 93 |
| PlayStation 4 | `tbd` | 1 |
| Xbox One | `tbd` | 0 |

### Игра 2 — `the-witcher-3-wild-hunt`

| Платформа | Metascore | Критиков |
|---|---|---|
| PC | **93** | 33 |
| Xbox One | **91** | 13 |
| PlayStation 4 | **92** | 80 |
| Nintendo Switch | `tbd` | — |

### Почему это доказательство, а не предположение

1. **Оценки реально различаются** (94/96/96 и 93/91/92). Если бы разметка дублировала одну
   агрегированную оценку, все значения совпадали бы.
2. Платформа и балл находятся **в одном DOM-контейнере**, а не сопоставляются по позиции.
3. Подтверждено на **двух** играх с разными наборами платформ.
4. Агрегированная оценка присутствует **отдельно** — блок «All Platforms» (для Elden Ring
   94 при 63 рецензиях), то есть per-platform данные не являются её копией.

### Значение `tbd`

Платформа может присутствовать **без** оценки (`tbd` — недостаточно рецензий). Это
нормальное состояние, а не ошибка парсинга: платформа сохраняется, `metascore = NULL`.

---

## 4. Userscore: что установлено

На странице игры отображается виджет «My Score» (личная оценка), а **не** агрегированный
Userscore по платформам. На `/user-reviews/` присутствует агрегированный Userscore (для
Elden Ring — **8.4**), но он относится к игре целиком, без разбивки по платформам.

При этом обнаружено, что страница содержит **сериализованное состояние приложения**
(Nuxt payload), где каждый пользовательский отзыв имеет структуру:

```json
{
  "id": "ad709db3-...",
  "quote": "...",
  "score": 10,
  "date": "2026-09-07",
  "author": "NextGas",
  "platform": { "id": 1912, "name": "PlayStation 5" }
}
```

Параметр `?platform=<slug>` на страницах отзывов принимает значения и возвращает 200.

**Следствие:** технически Userscore по платформе можно вычислить, усреднив отзывы с
соответствующим `platform`. Но это будет **наша агрегация, а не оценка Metacritic**.

---

## 5. Решение по хранению

В соответствии с требованием «не создавать ложную связь score → platform»:

- **Metascore** сохраняется на платформу с `score_scope = 'platform'`.
- **Userscore** сохраняется с `score_scope = 'overall'` и **явной пометкой в UI**,
  что оценка общая для игры, а не платформенная.
- Вычисленный нами средний Userscore по платформе **на MVP не используется** — выдавать
  собственную агрегацию за оценку Metacritic означало бы ровно ту ложную связь, которую
  запрещено создавать. Схема допускает добавление позже под отдельным значением
  `score_scope = 'derived'` (см. §6).

---

## 6. Возможное развитие (не входит в MVP)

Если потребуется Userscore по платформам, схема поддерживает `score_scope = 'derived'` с
обязательным сохранением `user_review_count` и маркировкой в UI («рассчитано по N отзывам»).
Это отдельное продуктовое решение, требующее вашего согласия.

---

## 7. Побочная находка, полезная для Фазы 3

Отзывы доступны в payload **структурированно** (id, quote, score, date, author, platform)
и не требуют разбора HTML-карточек. Это устойчивее к редизайну.

**Стратегия парсинга отзывов:** payload как основной источник, HTML-разметка карточек как
fallback. Оба варианта покрываются golden-file тестами.

> Оговорка: payload — внутренняя структура фреймворка, не публичный контракт. Поэтому он
> используется как *предпочтительный*, но не единственный путь, и обязателен fallback.

---

## 8. Влияние на схему БД

```sql
game_platforms (
  metascore        SMALLINT NULL,      -- NULL при 'tbd'
  metascore_scope  TEXT NOT NULL,      -- 'platform' (доказано)
  userscore        NUMERIC(3,1) NULL,
  userscore_scope  TEXT NOT NULL,      -- 'overall' (по умолчанию)
  critic_count     INT NULL,
  user_count       INT NULL
)
```

Раздельные `metascore_scope` и `userscore_scope` необходимы: у двух метрик **разная**
достоверность привязки к платформе. Один общий `score_scope` вынудил бы либо занижать
Metascore, либо завышать доверие к Userscore.

---

## 9. Устойчивость и контроль

- Селектор `title` внутри `game-platform-logo` — единственная точка зависимости от вёрстки
  для платформ; покрывается golden-file тестами с фикстурами `elden-ring` и
  `the-witcher-3-wild-hunt`.
- Рост доли игр с нулём распознанных платформ — сигнал мониторинга о смене разметки.
- Все фикстуры зафиксированы на дату исследования.

## 10. Проверенные URL

| URL | Код | Назначение |
|---|---|---|
| `/game/elden-ring/` | 200 | Карточка, per-platform Metascore |
| `/game/the-witcher-3-wild-hunt/` | 200 | Контрольная проверка |
| `/game/elden-ring/user-reviews/` | 200 | Агрегированный Userscore (8.4) |
| `/game/elden-ring/user-reviews/?platform=playstation-5` | 200 | Фильтр по платформе работает |
| `/game/elden-ring/platform/playstation-5/` | 404 | Такого шаблона нет |
